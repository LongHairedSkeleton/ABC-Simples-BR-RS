Aprender o alfabeto pode ser um jogo

ABC Simples é um joguinho de alfabetização feito para crianças dos anos iniciais, criado por dois estudantes do 9º ano de uma escola pública. Direto no navegador, sem precisar instalar nada.

B

O que é o ABC Simples

O jogo apresenta as letras do alfabeto de um jeito simples e divertido, ajudando crianças pequenas a reconhecer letras, sons e formar as primeiras palavras, além da sua parte de matemática focada no raciocínio lógico e nas operações matemáticas básicas. Foi pensado para ser usado em sala de aula ou em casa, com o apoio de um professor.

Feito na engine Godot, roda direto no navegador — funciona em computadores fracos como o ChromeBook e a maioria dos tablets.

C

Jogue agora, direto no navegador

O jogo só carrega quando você clicar em jogar.

Se o jogo não carregar, verifique se o navegador tem WebGL habilitado. Recomendado: Chrome ou Edge atualizados.

D

Jogabilidade

O ABC Simples oferece uma experiência de jogo envolvente e educativa, com níveis progressivos que desafiam as crianças a aprenderem o alfabeto de forma lúdica. A jogabilidade foi projetada para ser intuitiva e acessível, permitindo que as crianças aprendam sobre o alfabeto de maneira lúdica e interativa, e treina seus conhecimentos matemáticos com questões desenvolvidas com o uso do BNCC (Base Nacional Comum Curricular).

A versão para o professor só está disponível para download por uma questão de logística.

Ver no GitHub

Ter uma página no GitHub é importante pra um projeto de jogo porque é lá que fica guardado o histórico completo do desenvolvimento — cada mudança no código, quando foi feita e por quê. Isso dá transparência: qualquer pessoa pode ver como o jogo foi construído, não só o resultado final.

Também é uma forma de mostrar organização e domínio técnico pra quem for avaliar o projeto (professores, banca, feira de ciências), além de servir como um "currículo" público — outras pessoas podem sugerir melhorias, reportar problemas, ou até se inspirar no projeto. E, na prática, funciona como um backup seguro do código, caso algo aconteça com os arquivos no computador.
